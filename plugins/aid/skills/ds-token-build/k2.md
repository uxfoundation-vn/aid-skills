# Thêm Component token

```
Primitive  →  Semantic  →  Component token  ←  component bind
```

Làm K1 trước (`k1.md`). K2 chỉ thêm một tầng ngoài cùng.

## Có cần K2 không
Hỏi người dùng trước khi dựng. K2 đáng làm khi:
- Nhiều đội cùng dùng DS, cần đổi riêng một component (nút chính hơi đậm hơn) mà không động tới `bg-primary` của cả hệ.
- Code bên dev cũng có tầng này (biến CSS `--button-bg`), muốn tên khớp 1:1.

Không đáng làm khi DS nhỏ, một đội: tầng này chỉ là bản sao tên Semantic, thêm việc mà không thêm gì. Khi đó dừng ở K1.

## Bước 1. Collection
- `Component` (tên theo hồ sơ), **1 mode**. Light/Dark và brand đã nằm ở Semantic và Theme, tầng này không cần mode.
- Tên: `<component>/<thuộc tính>[-<trạng thái>]`, theo tên component trong code: `button/bg`, `button/bg-hover`, `button/text`, `input/border`, `input/border-focus`.
- Mỗi token **chỉ mở scope đúng thuộc tính tên nó nói tới** (S6): `button/bg` → `FRAME_FILL`; `button/text` → `TEXT_FILL`; `button/radius` → `CORNER_RADIUS`.

## Bước 2. Token cần tạo
Không tạo cho mọi thuộc tính của mọi component. Chỉ tạo cho thuộc tính:
- Mang dấu ấn riêng của component (nền, chữ, viền, bo góc của nút; viền và nền của ô nhập).
- Có thể cần chỉnh riêng sau này.

Khoảng cách bên trong (padding, gap) thường để Semantic `spacing`, không cần token riêng.

Mọi token Component **trỏ vào Semantic**, không trỏ Primitive hay Theme (F2):

```js
{ collection: 'Component', name: 'button/bg', type: 'COLOR', scopes: ['FRAME_FILL'], values: { Value: { alias: 'Semantic:bg/bg-primary' } } },
{ collection: 'Component', name: 'button/bg-hover', type: 'COLOR', scopes: ['FRAME_FILL'], values: { Value: { alias: 'Semantic:bg/bg-primary-hover' } } },
{ collection: 'Component', name: 'button/text', type: 'COLOR', scopes: ['TEXT_FILL'], values: { Value: { alias: 'Semantic:text/text-oncolor' } } },
{ collection: 'Component', name: 'button/radius', type: 'FLOAT', scopes: ['CORNER_RADIUS'], values: { Value: { alias: 'Semantic:radius/radius-md' } } },
```

## Bước 3. Gắn
Component bind vào token của chính nó (`Button` → `button/*`). Thuộc tính nào không có token Component thì bind Semantic. **Không** để Button dùng `input/*` hay ngược lại.

## Bước 4. Hồ sơ
Ghi `Khung: K2` và dòng `Component` trong bảng Collection. Audit binding sẽ coi tầng Component là tầng ngoài cùng.

## Lỗi hay gặp
- Token Component trỏ thẳng Primitive (`button/bg` → `blue-600`): đổi Light/Dark thì nút không đổi (F2).
- Token Component mở `All scopes`: `button/bg` hiện trong picker của mọi layer, người khác dùng cho card (S2, S6).
- Tầng Component chỉ chép tên Semantic, không có token nào khác giá trị Semantic: dấu hiệu chưa cần K2.
